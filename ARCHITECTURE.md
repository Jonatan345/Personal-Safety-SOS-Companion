# Architecture — SOS Companion

## Current Stage

This repository is a Flutter project created with `flutter create .`. It is
currently at the UI-prototype and navigation-skeleton stage (P3). The screens
use simulated monitoring and incident events; sensor, location, database, and
SMS integrations have not been implemented yet.

## Current Stack

- Flutter and Dart
- Material 3 UI
- Flutter widget tests
- Native platform runners generated by Flutter

## Planned Integrations

- `sensors_plus` for accelerometer-based shake/fall detection
- `geolocator` for the location captured after an incident
- `record` for microphone amplitude monitoring
- Hive for offline incident history
- A platform-supported SMS or notification integration for alerts

These packages should be added to `pubspec.yaml` only in the meeting where the
related feature is implemented.

## Generated Folders

Flutter creates `.dart_tool/`, `build/`, `.idea/`, and `sos_companion.iml`
locally. They support development tools and builds, but are excluded from Git
by `.gitignore`. The platform folders (`android/`, `ios/`, `web/`, `linux/`,
`macos/`, and `windows/`) are source configuration and should remain tracked.

## App Flow (Current Simulation)


Home → Monitoring → Simulate Incident → Countdown → History
                     └→ Cancel → Monitoring


## Target Data Flow (P6+)


Accelerometer / microphone event
  → incident-detection service
  → location service
  → countdown and user cancellation option
  → local incident storage
  → emergency alert


## Future Source Folders

When the real integrations begin, add these folders under `lib/`:


services/  # Sensor, location, storage, and alert integrations
utils/     # Shared constants and helper functions


Keeping them out until they contain real code avoids empty placeholder files.
